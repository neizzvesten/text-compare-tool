# Text Compare Tool — прототип для лингвистической экспертизы

Русскоязычное Streamlit-приложение для первичного сравнения двух текстов и предварительного поиска разных типов сходства.

## Возможности

- вставка двух текстов в браузер;
- загрузка TXT, MD, DOCX и PDF;
- поиск дословных последовательностей слов;
- поиск частичных совпадений;
- лексическое сравнение на основе лемматизации (если доступен `pymorphy3`);
- предварительная оценка грамматического/синтаксического сходства по последовательностям частей речи;
- семантический/лексико-статистический модуль. Без дополнительной sentence-embedding модели используется TF-IDF cosine, который **не является полноценным пониманием смысла**;
- фильтрация результатов и экспорт CSV/HTML.

## Запуск на компьютере

Требуется Python 3.10–3.12.

```bash
python -m venv .venv
```

Windows:

```powershell
.venv\Scripts\activate
```

macOS/Linux:

```bash
source .venv/bin/activate
```

Установка и запуск:

```bash
pip install -r requirements.txt
streamlit run app.py
```

Браузер откроется автоматически. Если нет, откройте адрес, который появится в терминале (обычно `http://localhost:8501`).

## Опубликовать через GitHub + Streamlit Community Cloud

1. Создайте новый **публичный** репозиторий на GitHub.
2. Загрузите в корень репозитория файлы `app.py`, `text_compare_tool.py`, `requirements.txt`, `README.md`, `.gitignore` и папку `.streamlit`.
3. Откройте https://share.streamlit.io/ и войдите через GitHub.
4. Нажмите **Create app**, выберите репозиторий и ветку (обычно `main`), укажите главный файл `app.py`.
5. Нажмите **Deploy**. После установки зависимостей появится публичная ссылка на приложение.

Если интерфейс или приложение не запускается, проверьте логи приложения на странице Streamlit Cloud. В качестве Python runtime используйте поддерживаемую версию Python 3.11 или 3.12.

## Важное ограничение конфиденциальности

В локальном запуске текст обрабатывается на компьютере пользователя. В облачной версии Streamlit код выполняется на удалённом сервере: не загружайте туда конфиденциальные экспертные материалы, персональные данные или документы, которые нельзя передавать третьим лицам. Для таких материалов используйте локальный запуск или согласуйте размещение с организацией.

## Методологические ограничения

- Программа обнаруживает кандидатов на совпадение, но не устанавливает факт плагиата.
- Дословные совпадения ищутся по последовательностям слов; пунктуационные различия могут не учитываться.
- Лексические и грамматические категории являются эвристическими и зависят от качества морфологического анализа.
- TF-IDF отражает лексическое сходство и может не находить парафразы без общих слов.
- Пороговые значения по умолчанию демонстрационные. Их следует калибровать на вручную размеченном наборе пар и оценивать precision, recall и F1.
